# 针锋 Crossfire v0.1.0

首个版本。把一个**已经定稿**的成果摆上台，让红队从指定维度分头攻击，把攻击拆成逐条可裁决的缺陷，由**人**逐条认定或驳回。

## 定位

AgentTeams 一类的协作型插件帮你把活干完；针锋帮你想清楚这活该不该这么干。它的质量门禁是**判断性**的（机器只挑错，结论永远由人下），与流程性门禁正交互补 —— 前者交付，后者验收。

四条边界：表态永远由人做（**没有任何"代表认定"的工具**）；不产出方案、不自动修复；红队专家只读；历史表态只用于去重与递进，绝不作为用户画像喂给红队。

## 本版包含

- **七步编排**：`crossfire_open` → `crossfire_stance` → `crossfire_attack` → `crossfire_collect` →（人在卡片上表态）→ `crossfire_finish` → `crossfire_recheck` / `crossfire_export`，外加专家侧的 `crossfire_report`。
- **Chat 卡片**（`tool.call.toolview`）：四态状态机、逐条缺陷内联表态（认定 / 驳回必填理由 / 待定，可互切）、影响条、立场可编辑。
- **按钮直推 host 状态机**：卡片上的"送红队上场 / 收集观点 / 定稿 / 开复审"经 RPC 直接推进，不必等一个模型回合；RPC 与工具驱动的是同一段引擎逻辑（`engine.ts`），不存在两份实现。
- **维度池**：固定 7 项（安全 / 数据 / 交互 / 性能 / 兼容 / 流程 / 反例）+ 用户自定义；落库维度必须是本次采用维度之一，越界者归一化并留可见标记。
- **证据分级**：`repro`（可复现步骤）与 `argument`（论证链），并在专家 persona 里明文**禁止**为设计类缺陷编造伪复现步骤。
- **闭环复审**：只核对上一轮已认定的缺陷是否修复，不许开新战线；超出强度档的复审上限需用户显式批准。
- **噪音过滤**：拦下 `auto-capture` 与行首进度叙述（真实数据里它们曾被当成缺陷收进裁决面），同时不误杀短的真缺陷。
- **设置页**：默认强度、维度池、预算、角色预设、阵容预设。

## 安装

```sh
dsh plugin --profile web add @huanlin/dsh-plugin-crossfire
```

安装后**重启 Harness 进程**并刷新浏览器。要求 DeepSeek Harness `0.2.0-rc.2+`。

## 与圆桌会议的关系

零代码耦合：不 import 圆桌任何模块、不读它的状态目录、不改它任何文件。两者的偏好文件与状态目录分别落在 `~/.dsh/crossfire/`、`<工作区>/.crossfire/` 与 `~/.dsh/roundtable/`、`<工作区>/.roundtable/`。

## 已知限制

- 状态锁是**进程内**的：多窗口同时操作同一场评审时，后写者覆盖前者（只靠原子写保证文件不写坏）。
- 自定义维度暂无"只在本次生效"的临时维度，只有全局预设。
- 未做向量检索、未接入外部干活模型 —— 这个插件本来也不干活。
