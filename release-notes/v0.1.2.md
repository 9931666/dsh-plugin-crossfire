# 针锋 Crossfire v0.1.2

**观点标题压缩版。** 只动展示逻辑，不碰红队协议、不碰提示词。

## 修了什么

### 观点标题过长且含无用信息（用户实测反馈）

**症状**：折叠态的标题一行显示不下，后面被截断；而且标题里塞了大段路径。

用户原话："标题过长，导致后面无法显示；其次这个标题有很多无用的信息，就比如说路径的位置。"

**根因不在提示词、也不在红队。** 红队的报告信封格式是 `观点 N（指向 X，维度Y）`，其中 `X`
是**完整路径**（如 `dsh-plugin-crossfire/src/client/ReviewCard.module.css:106-176`）——
红队写完整路径是**对的**，审计时要能定位到文件。问题出在展示层：
`defectTitle()` 把整个前缀**原样当标题**返回，40 多字符的路径直接把 80 字上限吃满。

**修法**：标题压缩成 `观点 N · 文件名:行号 · 维度`。

| | 改前 | 改后 |
| --- | --- | --- |
| 标题 | `观点 2（指向 dsh-plugin-crossfire/src/client/ReviewCard.module.css:106-176，维度 交…` | `观点 2 · ReviewCard.module.css:106-176 · 交互` |

三条刻意的设计：

1. **完整路径仍然留在缺陷正文里**（展开即可看到）—— 可追溯性一点没丢，只是不再占标题。
2. **行号保留**（`ReviewCard.module.css:106-176`），因为它是"跳到哪一行"的关键信息。
3. **形状不认识时原样退回**（例如旧格式 `观点 2 (指向 y)`、或括号里缺 `维度`）——
   不硬拼一个残缺标题。

Windows 反斜杠路径（`src\client\wire.ts:205-215`）同样压成文件名。

## 新增断言

`test/review-card.test.mjs` 增补 5 条，覆盖：完整路径压缩、反斜杠路径、裸文件名、
"形状不认识时退回原前缀"、以及"压缩结果必须显著短于原始长信封且仍受 80 字上限约束"。

## 安装

```sh
dsh plugin --profile web add @y9931666/dsh-plugin-crossfire
```

装后**重启 DeepSeek Harness 进程**并刷新浏览器。要求 DeepSeek Harness `0.2.0-rc.2+`、Node `>= 22`。
