# v0.1.3 — 界面视觉优化

本版只改界面，不改任何工具语义、状态机与数据格式。

## 评审卡片

- **状态色条**：每条缺陷左侧 3px 竖条按表态着色（认定=绿 / 驳回=红 / 待定=灰）。一条评审常有十几条缺陷，此前只能靠底部按钮描边逐条辨认状态，现在分布一眼可见。
- **间距与规格**：缺陷卡间距 4px → 8px，内边距 10→12，圆角 8→10，正文行高 1.65。
- **三态按钮**：统一 28px 高，不再随内边距漂移。
- **折叠标题**：信封压缩失败时退成「观点 N · 核心句」，不再把完整定位串（`F:\…\ReviewCard.tsx:154-…`）塞进标题；完整路径仍保留在展开后的正文里。
- **状态区文案**：「待定 9 / 表态 9」→「待定 9 / 共 9 条」，与左侧「待裁决」药丸不再重复。

## 设置页

- 区块改为**卡片分组**（边框 + 12px 圆角 + 浅底 + 16px 内边距），首个标题区块不套卡片。
- 控件统一：输入 32px 高 / 8px 圆角 / 320 宽；分段按钮从连体改为有间隙的胶囊组。
- 新增长度为 16×16 的内联 SVG 图标（`src/client/icons.tsx`）：零依赖、`currentColor` 随主题变色。

## 测试

- `test/review-card.test.mjs` 更新标题兜底断言；全量 226 项通过。
