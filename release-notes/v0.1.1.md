# 针锋 Crossfire v0.1.1

修复版。全部改动来自**用针锋自己审自己**的两轮红队评审（GPT-5.6-Terra 与默认路由各一轮），
以及评审过程中暴露出来的一个真实可用性缺陷。

## 修了什么

### 1. 设置页**完全无法保存**（最严重）

**症状**：角色预设、阵容预设、默认强度、预算**全部存不进去**，界面显示「保存失败」。

**根因**（不是 UI 问题，是身份问题）：宿主的 slot 契约里，`settings.section` 的
`standardProps` **不含 `sessionId`**（只有 `conversation.view` / `tool.call.toolview` 含），
而 `crossfire/prefs.set` 在宿主侧要求"必须声称一个身份"。于是卡片里能保存、设置页必然失败。

**修法**：新增 `src/client/session-cache.ts`，把会话标签页/轨迹卡片从宿主注入里拿到的**真实**
身份幂等记下来，设置页提交时声明同一个值。缓存为空时**绝不编造身份**（宁可让宿主按规则拒绝）。

### 2. 「打穿立场」链路从未生效

**症状**：专家在发言里明明写了"针对立场：打穿"，但每条缺陷的 `strikesStance` 都是 `false` ——
卡片上的「打穿立场」标签和"打穿优先排序"是死的。

**根因**：`split.ts` 的 `splitUtterance()` 被要求判断"是否打穿立场"，但它的参数里
**根本没有立场文本**，提示词只能靠正文里的字面标记去猜。

**修法**：立场全文随拆分请求下发；立场为空时在提示词里明说"未填写立场、不得标打穿"；
另加一道本地兜底，在 LLM 拆分失败退到启发式时仍能识别「针对立场：打穿」
（并特意区分「**未**打穿」，不让子串误匹配）。

### 3. 视觉与缓存

- **状态药丸四态同色**：顶部状态区的药丸底色此前恒为品牌蓝，而抬头徽章是四态四色，
  于是同一句「攻击中」在同一屏以黄色与蓝色各出现一次。现在药丸与徽章共用同一套主题令牌。
- **折叠态标题溢出**：标题行此前没有单行约束，最长 80 字的标题会把折叠体撑成 2–4 行。
  现在 `nowrap + ellipsis + overflow-wrap: anywhere`。
- **客户端废掉宿主的 ETag/304**：`fetchReviews` 用了 `cache: 'no-store'`，浏览器因此
  永不回传 `If-None-Match`，每 2 秒一次全量读盘 + 全量传输。改为 `no-cache`
  （语义仍是"每次回源校验"，但允许保存副本）。

## 版本号

`package.json` 与 `src/version.ts` 必须逐字一致（`test/version.test.mjs` 强制）。

## 安装

```sh
dsh plugin --profile web add @y9931666/dsh-plugin-crossfire
```

安装后**重启 Harness 进程**并刷新浏览器。要求 DeepSeek Harness `0.2.0-rc.2+`。

## 已知限制（未变）

- 状态锁仍是**进程内**的：多窗口同时操作同一场评审时，后写者覆盖前者。
- 设置页的身份来自浏览器侧缓存：**冷启动后直接打开设置页**、且本次会话从未渲染过
  「针锋」标签页或任意一张卡片时，保存仍会被宿主拒绝（这是刻意的 —— 插件不伪造身份）。
  看一眼「针锋」标签页再保存即可。
